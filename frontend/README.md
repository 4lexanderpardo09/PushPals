# PushPals Frontend — Isometric Pixel-Art Office

## Stack
React 19, Three.js (R3F + Drei), Zustand, TypeScript, Vite

## Scene Requirements Checklist

### Room Structure
- [ ] Irregular polygon floor plan
- [ ] Dark floor tiles with circuit lines
- [ ] Dark gray block walls with green reflections

### Main Signage
- [ ] PushPals neon sign (green, pixel text)
- [ ] "AI CODE REVIEW AGENTS" subtitle
- [ ] GitHub Octocat neon logo

### Control Panel
- [ ] Red emergency box with switch (left of sign)

### Task Board
- [ ] "TODAY'S MISSION" whiteboard
- [ ] Checkbox list (REVIEW CODE, CATCH BUGS, IMPROVE DOCS, KEEP CODE CLEAN)

### Central Server
- [ ] Raised platform with steps
- [ ] Server cube with green glow panels
- [ ] Cable connections radiating outward

### System Status Screen
- [ ] Large wall screen (top-center)
- [ ] Checklist: GITHUB CONNECTED, WEBHOOK ACTIVE, AI PROVIDER ONLINE, AGENTS READY

### Live Feed Screen
- [ ] Right wall screen
- [ ] Scrolling event log (Push received → Comment posted)

### Workstations (3)
- [ ] **QA Agent** (bottom-left): 2 monitors, character with red cap
- [ ] **Reviewer Agent** (right): 3 monitors, character with green shirt
- [ ] **Docs Agent** (bottom-center): 1 monitor, character with purple shirt
- [ ] Each: desk, chair, keyboard, mouse, coffee mug, plant

### Furniture
- [ ] Filing cabinet (left side)
- [ ] Shelves (top-right, bottom-left)
- [ ] Water cooler (right side)
- [ ] Potted plants (multiple locations)
- [ ] Cardboard boxes
- [ ] Trash can
- [ ] Rug with "SHIP · REVIEW · IMPROVE" text

### Cable Infrastructure
- [ ] Screen cables to server
- [ ] Floor circuit lines between tiles
- [ ] Network lines to workstations

### Lighting
- [ ] Green neon glow from signs/screens
- [ ] White glow from GitHub logo
- [ ] Blue ambient reflections
- [ ] Dark cyberpunk atmosphere

### Real-time Integration
- [ ] WebSocket connection to backend `/ws`
- [ ] Agent state tracking (idle/running/done/error)
- [ ] Character animations per state
- [ ] Live Feed scrolls with real events
- [ ] System Status updates dynamically
